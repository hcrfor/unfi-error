# 산림 도시조사 데이터 오류 검수 시스템 (unfi-error)

산림청 도시산림자원조사 및 국가산림자원조사(NFI) 엑셀 야장 데이터의 정밀 오류 검증 및 리포트 자동 생성 시스템입니다.

---

## 🌟 주요 기능 및 검증 규칙

1. **임분현황조사표 층위 검증 및 덩굴류 제외**:
   - `하층임목조사표(임목조사)` 및 `하층임목조사표(군락조사)`에 기록된 덩굴류(칡, 담쟁이덩굴, 노박덩굴, 등나무, 머루 등)는 수고가 아무리 높아도 **상층, 중층, 하층 층위 구간 및 최대 수고 수종 산정에서 제외**됩니다.
   - `임분현황조사표`의 `상층(종명)`, `중층(종명)`, `하층(종명)`에 덩굴류가 기재된 경우 오류로 검출합니다.
2. **층위 범위 및 피도 연결성 검증**:
   - 상층, 중층, 하층 범위(수고 구간) 연결성 및 형식(`시작~끝`) 검증
   - 각 층의 피도 최댓값과 전체피도 일치 여부 검증
3. **일반·토지 및 임목 조사 항목 정밀 검증**:
   - 도로거리, 표고(기준 좌표 대비 오차 포함), 방위각 정수 및 유효 범위 검증
   - 구조물 부재 시 특이사항 기재(`구조물없음`) 여부 검증
   - 결함 열, 평균흉고직경, 본수, 거리 등 정밀 수치 규칙 검증
4. **대시보드 웹 애플리케이션 제공**:
   - Flask 기반의 직관적인 웹 GUI (`web_app.py`)
   - 윈도우 폴더 대화상자 연동, 실시간 프로그레스 바, 요약 통계 및 엑셀 리포트 다운로드 지원

## 🚀 실행 방법

### 1. 가상환경 및 필수 패키지 설치
```bash
pip install flask openpyxl
```

### 2. 웹 검수 프로그램 실행
배치 파일을 더블 클릭하거나 콘솔에서 실행합니다:
```bash
검수프로그램_실행.bat
# 또는
python web_app.py
```
브라우저에서 `http://127.0.0.1:5000`으로 접속하여 검수를 진행합니다.

### 3. CLI 스크립트 실행 (단독 분석)
```bash
python analyze_errors.py
```

## 📁 디렉터리 구조
- `excel_inspector.py`: 핵심 오류 검수 엔진 및 규칙 정의 모듈
- `web_app.py`: 웹 서버 및 REST API 엔드포인트
- `analyze_errors.py`: 단독 실행용 오류 분석 스크립트
- `templates/`: 대시보드 웹 템플릿 (`index.html`)
- `static/`: 대시보드 UI 스타일(`style.css`) 및 인터랙션 스크립트(`app.js`)
- `2026 도시 조사결과표(한성안).xlsx`: 기준 표본점 대조용 마스터 파일
